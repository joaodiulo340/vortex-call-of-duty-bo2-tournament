# VORTEX Tournament Manager

Projeto React + TypeScript preparado para Vite e Tailwind CSS.

## Desenvolvimento

1. `npm install`
2. `npm run dev`

## Publicação

Importar este repositório no Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.

## Nota importante

Esta versão preserva o comportamento atual do código, que usa `localStorage` no navegador. Para inscrições e resultados sincronizados entre visitantes, é necessário configurar Supabase e políticas de segurança antes de abrir inscrições públicas.
